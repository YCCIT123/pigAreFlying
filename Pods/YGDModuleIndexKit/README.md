# YGDModuleIndexKit

Feature module index bootstrap for pigAreFlying.

## Example

```bash
cd Example
pod install
open YGDModuleIndexKit.xcworkspace
```

## Installation

```ruby
source 'https://github.com/best-pig/YGDSpecs.git'
source 'https://cdn.cocoapods.org/'

pod 'YGDModuleIndexKit', '0.1.1'
```
