# YGDModuleBridgeKit

Feature module bridge contracts for pigAreFlying.

## Example

```bash
cd Example
pod install
open YGDModuleBridgeKit.xcworkspace
```

## Installation

```ruby
source 'https://github.com/best-pig/YGDSpecs.git'
source 'https://cdn.cocoapods.org/'

pod 'YGDModuleBridgeKit', '0.1.1'
```
